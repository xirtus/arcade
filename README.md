# Xirtus Arcade

All-ages browser games and experiments. Each game is its own repository with
source, license, asset notes, and a versioned screenshot.

![ZENDRIVE](https://raw.githubusercontent.com/xirtus/zendrive/main/docs/screenshot.jpg)

| Game | What it is | License |
|---|---|---|
| [ZENDRIVE](https://github.com/xirtus/zendrive) | Procedural vaporwave racer; no build step | MIT |
| [MANDELPOD](https://github.com/xirtus/mandalpod) | Psychedelic octopus platformer | MIT |
| [MACHINE ELF](https://github.com/xirtus/machine-elf) | WebGPU/TSL fractal rail shooter | MIT |
| [RABBITVERSE](https://github.com/xirtus/rabbitverse) | Procedural mascot platformer | MIT |
| [TSUNAMI](https://github.com/xirtus/tsunami-surf) | Endless giant-wave surf game | GPL-2.0 |
| [Rubber Duckie River Race](https://github.com/xirtus/rubber-duckie-river-race) | 100-duck river race | MIT |
| [KRIKET v1](https://github.com/xirtus/kriket) | First playable cricket sim | MIT |
| [KRIKET v2](https://github.com/xirtus/kriket-2) | Physics/presentation pass | MIT |
| [KRIKET v3](https://github.com/xirtus/kriket-3) | Bat-cam/fielding pass | MIT |
| [MANDELHOP](https://github.com/xirtus/mandelhop) | Infinite fractal-garden frogger | MIT |
| [Damn Beavers](https://github.com/xirtus/dambeavers) | Systemic beaver-civilization sim | MIT |
| [NARAYANA](https://github.com/xirtus/narayana-the-hadal-cycle) | Procedural underwater adventure | MIT |
| [Surf Mechanics](https://github.com/xirtus/surf-mechanics) | Curated KSPS code archive | MIT |

## Notes

- **TSUNAMI** is GPL-2.0 because it includes a GPL-2.0 Tux model. The other games
  are MIT (code) with CC BY 4.0 original assets unless their notices say otherwise.
- **Surf Mechanics** is a code archive, not a playable build.
- **Beyond Fable** is not here: it is a fork of `xikhar/beyond-fable` by Shikhar,
  not this portfolio's work.
- Adult projects (`rosebud`, Tartarus/Fantasia/Stereopolis adult content) are not
  part of the arcade and are never linked from it.
